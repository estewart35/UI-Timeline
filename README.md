# 📌 UI-Timeline

> An interactive timeline that showcases the evolution of web design trends over the years through an engaging, animated experience.

---

## 🚀 Live Demo  
[View Project](https://ui-timeline.netlify.app/)

---

## ✨ Features  
- Smooth animations for an engaging and dynamic browsing experience
- Keyboard navigation for accessible, intuitive timeline control
- Scoped styling per section to visually represent each UI design era

---

## 🛠️ Tech Stack  
- **Frontend:** React, JavaScript, Bootstrap, CSS, Framer Motion
- **Hosting:** Netlify

## ⚡ Getting Started (React + Vite)

Clone the repo:  
```bash
git clone https://github.com/estewart35/UI-Timeline.git
cd UI-Timeline
```

Install dependencies and run locally:
```bash
npm install
npm run dev
```
